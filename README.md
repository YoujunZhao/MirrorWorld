# MirrorWorld: Taming Video Diffusion Models for Mirror Reflection Generation

**Youjun Zhao<sup>1</sup> · Alex Warren<sup>2</sup> · Gary K.L. Tam<sup>2</sup> · Rynson W.H. Lau<sup>1</sup>**

<sup>1</sup>City University of Hong Kong · <sup>2</sup>Swansea University

[Project Page](https://youjunzhao.github.io/MirrorWorld/) · **Paper — Coming soon** · [Code](https://github.com/YoujunZhao/MirrorWorld)

</div>

MirrorWorld is a reflection-aware video inpainting framework that models the relationship between visible scene content and missing mirror regions. Semantic Relation Distillation learns **what** should be reflected, while Geometric Transformation Alignment learns **how** the reflected content should be spatially arranged.

The project introduces a unified video mirror reflection reconstruction benchmark built from VMD-D, ZOOM, MMD, and DVMD-D. The project page includes scene-matched comparisons with MirrorFusion, MirrorVerse, VideoPainter, and VACE, together with additional MirrorWorld video results.
